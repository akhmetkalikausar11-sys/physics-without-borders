PWB — Physics Without Borders (beta)
====================================

Состав:
- index.html — главная страница сайта (именно этот файл называется index.html)
- mechanics.html — лаборатория механики
- aerodynamics.html — лаборатория аэродинамики
- space.html — лаборатория физики космоса
- experiments.html — таблица измерений и график
- README.txt — эта инструкция

КАК ЗАПУСТИТЬ:
1. Распакуй ZIP-архив.
2. Для простой проверки открой index.html в браузере.
3. Для публикации загрузи ВСЕ файлы в один Replit HTML/CSS/JS project.
4. Не переименовывай index.html: хостинг открывает его как главную страницу.
5. После публикации Replit выдаст публичную ссылку.
6. Для Google Sites: Вставка -> Встроить -> По URL. Для отдельных разделов можно вставить URL страницы mechanics.html, aerodynamics.html и т.д.

Важно:
- Это учебные модели, не профессиональные инженерные симуляторы.
- На некоторых телефонах/браузерах локальное открытие файлов может ограничивать отдельные функции; публикация на хостинге предпочтительнее.
- Проверь все модели и формулы до публичного запуска.
