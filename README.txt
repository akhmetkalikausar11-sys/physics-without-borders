PWB — PHYSICS WITHOUT BORDERS (Единый сайт)
============================================

В архиве собраны все 5 разделов платформы в едином тёмно-синем дизайне:
- index.html        — Главная страница с карточками всех разделов
- mechanics.html    — Лаборатория механики (интерактивный математический маятник и график угла)
- aerodynamics.html — Лаборатория аэродинамики (модель крыла в потоке воздуха и подъёмная сила)
- space.html        — Космическая лаборатория (3D-космос, планеты, звёзды, чёрные дыры, атлас и расчёты)
- experiments.html  — Лаборатория экспериментов (журнал измерений, средняя скорость и график)
- css/style.css     — Общие стили для всех страниц
- js/space_data.js  — База космических тел
- js/space_app.js   — Скрипт 3D-космоса, атласа и астрофизических расчётов

Как загрузить на GitHub:
1. Распакуйте архив PWB_FULL_SITE.zip в отдельную папку.
2. Загрузите все файлы и папки (index.html, mechanics.html, aerodynamics.html, space.html, experiments.html, README.txt, css, js) в репозиторий physics-without-borders на GitHub и нажмите Commit changes.
