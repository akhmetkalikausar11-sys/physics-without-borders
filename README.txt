PWB — UNIVERSE LAB (Physics Without Borders)
============================================

Единая интерактивная космическая и физическая лаборатория.

Структура архива:
- index.html      — главная страница с общей навигацией (3D-Космос, Атлас, Сравнение, Физическая лаборатория)
- css/style.css   — единый дизайн и адаптивная вёрстка (поддержка ПК и смартфонов)
- js/data.js      — база данных космических объектов (планеты, спутники, звёзды, чёрные дыры, галактики, туманности, кометы, астероиды, пульсары, сверхновые)
- js/app.js       — 3D-движок рендеринга, управление камерой, сравнение тел, физический калькулятор и графики

Как опубликовать на GitHub Pages:
1. Распакуйте архив PWB_UNIVERSE_LAB.zip в отдельную папку.
2. Загрузите все файлы и папки (index.html, папку css, папку js и README.txt) в корень вашего репозитория на GitHub.
3. Откройте опубликованный сайт по ссылке GitHub Pages.
